# Sales Performance & Customer Analytics Dashboard

## Overview
This project is an interactive Power BI dashboard designed to analyze sales performance, product trends, and customer demographics. The dashboard provides insights into key business metrics, sales targets, product categories, and customer characteristics through interactive visualizations.

## Dashboard Pages

### 1. Overview
Provides a high-level view of sales performance and business KPIs, including:
- Total Revenue
- Sales Target Monitoring
- Return Target Monitoring
- Sales trends over time
- Sales distribution by category and subcategory
- Geographic sales analysis

### 2. Products
A drill-through page designed for detailed product-level analysis, allowing users to explore individual product performance.

### 3. Customers
Provides customer-related insights through demographic analysis, including:
- Customer age distribution
- Gender analysis
- Customer status analysis
- Occupation-based analysis

## Tools & Technologies
- Power BI

## Features
- Interactive filters and slicers
